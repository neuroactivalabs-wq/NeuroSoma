# NeuroSoma · Calma y Bienestar (PWA)

App web instalable (PWA) de Neuroactiva Labs. Sitio estático: no requiere compilación.

- Publicación: Cloudflare Pages, carpeta raíz del repositorio, sin comando de build.
- Configuración de venta: `js/config.js` (WhatsApp, catálogo, precio).
- Los códigos VIP se firman con una llave privada que NO está en este repositorio; aquí solo hay la llave pública (comprueba, no crea).
- Al cambiar archivos, sube la versión de caché en `sw.js` (`ns-vN`) para que los teléfonos se actualicen.
- NeuroSoma no sustituye atención médica ni psicológica.
